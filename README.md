# API Aeroporto — projeto UPSkill

Projeto de aprendizagem em Node.js e Express, com uma base de dados MySQL, desenvolvido durante a formação UPSkill. Inclui rotas e operações relacionadas com aeroportos, aviões, passageiros, voos, bilhetes e rotas.

## Configuração local

1. Instalar as dependências com `npm install`.
2. Copiar `.env.example` para `.env` e preencher **apenas localmente** os dados da sua base de dados.
3. Preparar a base de dados MySQL usando o material SQL do projeto, quando aplicável.
4. Iniciar a aplicação conforme a configuração de execução do projeto.

O ficheiro `.env` real não deve ser enviado para o GitHub. O projeto é académico e pode necessitar de adaptações para funcionar em ambientes atuais.

## Segurança

As configurações sensíveis foram removidas da versão atual do repositório. **A remoção não apaga os valores do histórico Git**; quaisquer credenciais reais anteriormente publicadas devem ser revogadas ou alteradas. Dependências e ficheiros locais são ignorados em novos commits por `.gitignore`.
